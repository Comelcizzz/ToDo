## D. Cache fingerprint

Replaced thin `trackId|fileSize|mtimeHash` with layered `AnalysisFingerprint`:

- normalized asset id
- file size + mtime hash
- sample rate, channel count, sample count
- fast content fingerprint (SHA-256 of head/mid/tail)
- optional full SHA-256
- analyzer algorithm version + schema version
- analysis settings hash
- role + section map hash

`AnalysisResultCache` rejects corrupted SHA mismatches and refuses partial (`complete=false`) writes.

Tests cover: same size+mtime content change, middle change, rename, track ID, algorithm version, settings, corruption, partial write.

## F. StereoWidth verification

Implementation: complementary one-pole split on Side only:

```
sideLow  = LPF(side)
sideHigh = side - sideLow   // exact complementary residual
sideOut  = sideLow * lowWidth + sideHigh * highWidth
```

Unity mode: `width=1`, `midGainDb=0`, `sideGainDb=0`, `lowBandMonoEnabled=false` → M/S identity (flat magnitude within float/smoother noise).

Low-band mono (product default): `lowWidth=0` discards side below cutoff — intentional mono bass, not full-band unity.

Verified: complementary split, unity residual, width=0 mono, anti-phase LF attenuation, no DC, SR×cutoff grid (44.1/48/96 kHz × 80/120/200/300 Hz).
